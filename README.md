# Economist討議プロジェクト アセットリポジトリ

The Economist記事を素材とした構造的ディベート練習の資産層。
討議そのものはClaude.aiのプロジェクトチャットで行い、本リポジトリは討議録・台帳・自動化を担う。

## ディレクトリ構成

```
sessions/      討議録（1セッション1ファイル、例: 016_uk-employment-tribunal-ai.md）
ledger/        セッション台帳・未決問い台帳・立場更新ログ
seeds/         週次の記事選定シード文書（定時タスクが生成）
templates/     討議録テンプレート
tasks/         Claude Code定時タスク用プロンプト
predictions/   第3段階用の予測台帳（ブライアースコア採点、未稼働）
```

## 運用フロー

1. 毎週金曜朝、Claude Codeのクラウド定時タスクが `tasks/weekly_seed.md` の指示に従い、`ledger/` を読んで候補記事を選定し `seeds/` にコミットする
2. 勝俣がシードを確認し、プロジェクトチャットで討議セッションを開始する（記事本文は手動で貼る）
3. セッション末に討議録を生成し、`sessions/` にコミットする（クロージング必須手順）
4. コミット時に `ledger/unresolved_questions.md` と `ledger/session_ledger.md` を同時更新する

## クロージング必須手順（コミット忘れ防止）

セッションを「クローズ」と宣言する前に、以下3点の完了を確認する。

- [ ] 討議録を `sessions/NNN_slug.md` として保存
- [ ] `ledger/session_ledger.md` に1行追加
- [ ] `ledger/unresolved_questions.md` の追加・解決を反映

この3点が揃わないうちはセッションをクローズしない。
台帳とチャットメモリが分岐した時点で両方の信頼性が失われるため、この手順が本構成の成否を分ける。

## 単一の真実源

セッション番号・未決問い・立場更新の正はすべて本リポジトリとする。
チャットのプロジェクトメモリは要約ベースで劣化するため、矛盾時はリポジトリを優先する。
