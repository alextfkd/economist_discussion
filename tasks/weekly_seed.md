# 週次シード生成タスク（Claude Codeクラウド定時タスク用プロンプト）

スケジュール：毎週金曜 07:00 JST

## 指示

あなたはEconomist討議プロジェクトの記事選定係である。
以下を順に実行せよ。

1. `ledger/unresolved_questions.md`、`ledger/session_ledger.md`、`ledger/principles.md` を読む
2. web検索でThe Economist最新号の目次相当情報（各セクションの記事タイトルと要旨）を収集する。本文のスクレイピングは行わない
3. 以下の選定基準で候補記事1本と次点1本を選ぶ
   - ①BFS原則：台帳のドメイン列を参照し、未踏または手薄なセクションを優先する。マクロ・金融への偏重を避ける
   - ②未決の問いへの接続：openな問いに接続する記事を加点する
   - ③機構密度：因果機構が明示的に論じられている記事を優先する
4. `seeds/YYYY-MM-DD_seed.md` を作成しコミットする

## シード文書の必須構成

- 候補記事：タイトル、セクション、URL
- 選定理由：2〜3行（どの基準に該当するか明示）
- 次点記事：タイトルと1行理由
- 再掲する未決の問い：候補記事に接続するopenな問いを番号付きで引用
- 想定される争点の予告：2〜3個（詳細な反論はセッション本番まで展開しない）

## 制約

- 記事本文の転載・長文引用はしない。要約は自分の言葉で3行以内
- 勝俣には拒否権がある。シードは提案であり確定ではない
- 目次情報が取得できなかった場合は、その旨と取得できた範囲を記録して終了する
